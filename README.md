## What it does

`main.ts` writes exactly one line to `/output/entry.txt`: a roast of an alarm
clock that rings at 6 AM on a Saturday morning.

> At 6 AM on a Saturday, my alarm clock screamed like a rooster that had unionised and was demanding overtime from a man still in his pyjamas.

## Run

```sh
node main.ts
```

Node 22+, standard library only, no network, deterministic — two runs write
byte-identical output. See [BUILD_LOG.md](BUILD_LOG.md) for verification.
